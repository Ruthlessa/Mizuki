# 概述

## 项目介绍

Mizuki 是一个基于 Astro 框架构建的现代化博客主题，具有以下特点：

### 核心功能

- **响应式设计**: 完美适配桌面端和移动端
- **多语言支持**: 支持中文、英文、日语、繁体中文
- **暗黑模式**: 支持明暗主题切换
- **音乐播放器**: 内置音乐播放功能
- **相册系统**: 支持图片相册展示
- **时间线**: 记录生活点滴
- **技能展示**: 展示个人技能栈
- **设备展示**: 展示个人设备收藏

### 技术栈

- **框架**: Astro 4.x
- **语言**: TypeScript
- **样式**: TailwindCSS 3
- **组件**: Svelte
- **图标**: Astro Icon / Material Symbols
- **动画**: GSAP / CSS Animations

### 架构设计

项目采用原子化设计原则，组件结构如下：

- **Atoms**: 基础原子组件（按钮、图标、链接等）
- **Molecules**: 分子组件（组合原子组件）
- **Organisms**: 组织组件（导航栏、页脚等）
- **Layouts**: 布局组件（主布局、网格布局等）
- **Widgets**: 侧边栏小部件（音乐播放器、日历、标签等）

### 目录结构

```
src/
├── components/       # 组件目录
├── config/          # 配置文件
├── content/         # 文章内容
├── data/            # 静态数据
├── i18n/           # 国际化
├── layouts/         # 布局组件
├── pages/          # 页面路由
├── plugins/        # 插件
└── scripts/        # 脚本文件
```

### 核心特性

1. **性能优化**: 使用 Astro 的静态站点生成能力，首屏加载速度快
2. **SEO 友好**: 完善的 meta 标签和结构化数据
3. **评论系统**: 支持 Twikoo 和 Giscus
4. **搜索功能**: 集成 Pagefind 全文搜索
5. **图片优化**: 自动 WebP 格式转换和懒加载
6. **动画效果**: 丰富的过渡动画和交互效果

### 部署方式

支持多种部署方式：

- Cloudflare Pages
- Vercel
- Netlify
- GitHub Pages
- 自建服务器
- Docker 容器

### 扩展能力

主题具有良好的扩展性，可以通过配置文件轻松自定义：

- 自定义颜色主题
- 自定义字体
- 自定义页面布局
- 添加新的侧边栏小部件
- 自定义页脚内容
