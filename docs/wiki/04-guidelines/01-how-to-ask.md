# 提问的艺术

## 核心前提

### 尊重他人时间

- 提问前先自行搜索和研究
- 准备好问题的上下文
- 明确问题的核心

### 清晰表达

- 使用简洁明了的语言
- 避免模糊和歧义
- 提供足够的信息

### 友好态度

- 使用礼貌的语气
- 尊重社区规则
- 感谢帮助你的人

## 提问格式

### 问题标题

清晰描述问题：

**推荐：**
```
[Bug] 导航栏在移动端显示异常
[Feature] 请求添加暗色模式支持
[Help] 如何配置评论系统
```

**不推荐：**
```
有问题
这个怎么弄
求助
```

### 问题描述

包含以下信息：

1. **问题现象**：发生了什么
2. **期望结果**：期望是什么
3. **复现步骤**：如何复现问题
4. **环境信息**：系统版本、浏览器、配置等
5. **错误日志**：相关的错误信息
6. **代码片段**：相关的代码

### 示例

```
**问题描述**：
导航栏在移动端（iPhone 14, iOS 16）显示异常，菜单按钮点击无响应。

**期望结果**：
菜单按钮点击后应弹出导航菜单。

**复现步骤**：
1. 在移动端访问网站
2. 点击导航栏的菜单按钮
3. 菜单没有弹出

**环境信息**：
- 浏览器：Safari 16
- 系统：iOS 16
- 主题版本：v1.0.0

**错误日志**：
控制台显示：Uncaught TypeError: Cannot read properties of undefined

**代码片段**：
```javascript
// 相关代码
const menuBtn = document.getElementById('menu-btn');
menuBtn.addEventListener('click', toggleMenu);
```
```

## 内容要求

### 信息完整性

- 提供足够的上下文
- 包含必要的截图或日志
- 说明已尝试的解决方案

### 代码规范

- 使用正确的代码格式
- 提供完整的代码片段
- 标注代码的位置

### 问题定位

- 尽量缩小问题范围
- 说明问题出现的条件
- 提供可复现的步骤

## 交流礼仪

### 提问前

1. 搜索文档和已有 issues
2. 查看常见问题解答
3. 尝试自行调试

### 提问时

1. 使用礼貌的语言
2. 清晰描述问题
3. 耐心等待回复

### 得到回答后

1. 感谢回答者
2. 测试解决方案
3. 反馈结果

## 问题速查

### 构建失败

**常见原因：**
- 依赖版本不兼容
- 配置文件错误
- 代码语法错误

**检查步骤：**
1. 查看构建日志
2. 检查依赖版本
3. 验证配置文件

### 样式异常

**常见原因：**
- CSS 冲突
- 响应式布局问题
- 浏览器兼容性

**检查步骤：**
1. 使用开发者工具检查
2. 验证 CSS 选择器
3. 测试不同浏览器

### 功能不生效

**常见原因：**
- JavaScript 错误
- 配置不正确
- 权限问题

**检查步骤：**
1. 查看控制台日志
2. 验证配置项
3. 检查权限设置

### 性能问题

**常见原因：**
- 资源过大
- 渲染阻塞
- 内存泄漏

**检查步骤：**
1. 使用性能分析工具
2. 检查资源大小
3. 优化关键路径

## 常见错误

### 不提供上下文

**错误示例：**
```
这个功能怎么用？
```

**正确示例：**
```
请问如何配置音乐播放器功能？我在 config.ts 中没有找到相关配置项。
```

### 不尊重他人

**错误示例：**
```
为什么没人回答我？
这个问题很简单啊！
```

**正确示例：**
```
请问有人能帮我看看这个问题吗？谢谢！
```

### 重复提问

**错误做法：**
在多个地方重复问相同的问题

**正确做法：**
先搜索是否已有答案，只在一个地方提问

### 期望即时回复

**错误做法：**
频繁催促回复

**正确做法：**
耐心等待，社区成员都是志愿者

## 反馈规范

### 问题解决后

1. 回复说明问题已解决
2. 分享解决方案
3. 关闭 issue

### 问题未解决

1. 提供更多信息
2. 尝试其他方法
3. 寻求其他渠道

### 感谢支持

- 对帮助你的人表示感谢
- 考虑贡献文档或代码
- 帮助其他有类似问题的人

## 贡献指南

### 报告问题

- 使用模板提交 issue
- 提供完整的信息
- 遵循社区规范

### 提交代码

- 遵循代码风格
- 添加测试用例
- 编写清晰的提交信息

### 改进文档

- 更新相关文档
- 添加示例代码
- 修复文档错误

## 总结

### 提问要点

1. **明确问题**：清晰描述问题现象和期望
2. **提供信息**：包含环境、日志、代码等
3. **友好礼貌**：使用礼貌的语言
4. **及时反馈**：回复解决方案的效果

### 学习资源

- 阅读官方文档
- 查看示例项目
- 参与社区讨论

### 持续改进

- 记录问题和解决方案
- 学习新的知识
- 分享经验给他人
