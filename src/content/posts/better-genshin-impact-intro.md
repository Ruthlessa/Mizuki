## 项目概述

**BetterGI**（Better Genshin Impact）是一个基于**计算机视觉技术**的开源辅助工具项目，旨在通过图像识别和模拟操作来自动化原神游戏中的各种日常任务，从而提升玩家的游戏体验。

> 仓库地址：[Ruthlessa/better-genshin-impact](https://github.com/Ruthlessa/better-genshin-impact)（forked from [babalae/better-genshin-impact](https://github.com/babalae/better-genshin-impact)）

该项目采用 **GPL-v3** 开源协议，主要使用 **C#** 语言开发（占比 99.1%），基于 **.NET 8** 运行时运行。

---

## 核心功能特性

BetterGI 提供了丰富多样的自动化功能，大致可分为以下几类：

### 实时任务（运行时自动触发）

| 功能 | 说明 |
|------|------|
| **自动拾取** | 遇到可交互/拾取内容时自动按 F 键，支持黑白名单配置 |
| **自动剧情** | 快速点击跳过剧情、自动选择选项、自动提交物品、关闭弹出书页等 |
| **自动邀约** | 自动选择邀约事件中的对话选项 |
| **快速传送** | 在地图上点击传送点后自动完成传送流程 |
| **半自动钓鱼** | AI 识别鱼漂，自动抛竿和收杆 |

### 独立任务（手动启动后自动执行）

| 功能 | 说明 |
|------|------|
| **全自动七圣召唤** | 完成角色邀请、每周来客挑战等 PVE 内容 |
| **自动伐木** | 利用「王树瑞佑」上下线刷新机制，挂机刷满一背包木材 |
| **自动秘境** | 全自动刷秘境、领取奖励 |
| **自动幽境危战** | 难度三刷圣遗物 |
| **全自动钓鱼** | 自动完成钓鱼并切换白天和晚上 |
| **自动地脉花** | 自动连续刷地脉花 |
| **自动音游** | 一键完成千音雅集专辑 |
| **自动烹饪** | 在完美区域完成食物烹饪 |
| **自动分解圣遗物** | 支持快速分解和规则匹配分解 |

### 全自动与辅助功能

| 功能 | 说明 |
|------|------|
| **一条龙** | 一键完成日常（使用历练点）并领取奖励 |
| **自动采集/挖矿/锄地** | 通过小地图识别完成路径导航 |
| **键鼠录制** | 录制回放键鼠操作 |
| **那维莱特转圈** | 长按快捷键持续旋转视角 |
| **快速圣遗物强化** | 跳过动画，快速+20 |
| **商店一键购买** | 快速清空活动兑换商店 |

## 技术架构

### 项目结构

```
better-genshin-impact/
├── BetterGenshinImpact/      # 主程序核心代码
├── Fischless.GameCapture/    # 游戏画面捕获模块
├── Fischless.HotkeyCapture/  # 热键捕获模块
├── Fischless.WindowsInput/    # Windows 输入模拟模块
├── Build/                    # 构建配置
├── Docs/                     # 文档
└── Test/                     # 测试代码
```

### 技术栈

- **编程语言**：C# (99.1%)
- **运行时**：.NET 8
- **核心技术**：
  - 计算机视觉（图像识别）
  - Windows API 模拟输入
  - 游戏画面捕获（GDI+ / DirectX）

### 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 或更高版本（64位） |
| 游戏分辨率 | 仅支持 16:9 分辨率（推荐 1920×1080 窗口化） |
| 硬件要求 | 中画质 60 帧流畅游玩原神 |
| 依赖环境 | .NET 8 运行时 |
| 特殊要求 | 需要以管理员权限运行 |

### 已知限制

1. 窗口大小变化、切换分辨率、切换显示器时需要重启软件
2. 不支持画面滤镜（HDR、N卡滤镜等）
3. 部分安全软件（360、自定义规则 WD）可能拦截模拟点击
4. 游戏亮度需保持默认设置

## 安全性说明

BetterGI 的设计理念是**不修改游戏文件、不读写游戏内存**，仅通过以下方式实现功能：

```
图像识别 → 决策判断 → 模拟键盘鼠标操作
```

> [!WARNING]
> 虽然技术上风险较低，但米哈游用户条款明确禁止第三方软件/模拟操作，请谨慎使用并保持低调。

## 使用方法

### 快速上手

1. 下载最新版本（[GitHub Releases](https://github.com/babalae/better-genshin-impact/releases)）
2. 安装 [.NET 8 运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/latest/runtime)
3. 以**管理员权限**启动程序
4. 在"启动"页选择截图方式
5. 点击启动按钮即可使用

### 详细文档

更多使用细节和功能配置请参考官方文档：[bettergi.com/doc.html](https://www.bettergi.com/doc.html)
